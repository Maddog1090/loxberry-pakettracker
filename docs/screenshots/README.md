# Screenshots

Ablage für Bilder der Weboberfläche, die in der Projekt-README eingebunden werden.

| Datei | Inhalt |
|---|---|
| `status.png` | Seite **Status** mit Zusammenfassung, Anbieter-Status und Slots (Testmodus) |
| `anbieter.png` | Seite **Anbieter** mit der Übersicht aller Paketdienste |
| `einstellungen.png` | Seite **Einstellungen**, Bereich E-Mail-Eingang |
| `hilfe.png` | Seite **Hilfe** mit dem Knopf „Ausführliche Anleitung öffnen“ |

Hinweise:
- Screenshots im **Testmodus** erstellen. Es dürfen keine echten Sendungsnummern, E-Mail-Adressen, Servernamen, IP-Adressen oder Tokens zu sehen sein. Der REST-Token auf der Einstellungsseite ist sichtbar, diesen Bereich also nicht aufnehmen oder schwärzen.
- PNG, Breite etwa 1200 px.
- Danach in `README.md` den auskommentierten Block im Abschnitt „Screenshots“ aktivieren.
