Getting started

  1. Test run: Shipments → number 00340434000000000001, carrier "Detect automatically" → Add shipment → Status → Update now. Slot 1 shows a simulated status.
  2. Check MQTT: LoxBerry → MQTT Gateway → Incoming Overview: entries {{BASE_TOPIC}}/… must appear.
  3. Set up Loxone (see below) while test mode is active.
  4. Set up and test the e-mail input (Settings → E-mail input) – required for Amazon, Hermes, DPD, GLS.
  5. Optionally enter the DHL API key and UPS credentials (Settings → Carriers).
  6. Switch off test mode (Settings → General) → Status → Update now → check the Carriers page.

Status codes 0–7

0Unknown (empty slot: used = 0)
1Announced
2In transit
3Out for delivery
4Delivered (in slots only on the delivery day)
5Ready for pickup
6Problem
7Returned (not in slots)

Carriers

  • DHL (API + e-mail): developer.dhl.com → My Apps → app with "Shipment Tracking – Unified" → Consumer Key → Settings → Carriers → DHL.
  • UPS (API + e-mail): developer.ups.com → Apps with product "Tracking" → Client ID and Secret → Settings → Carriers → UPS.
  • Amazon, Hermes, DPD, GLS (e-mail only): enable e-mail notifications at the carrier and set up the e-mail input.
  • A manually selected carrier always wins over automatic detection. 12- and 14-digit numbers are ambiguous.

MQTT, Loxone, REST

  • Topics: {{BASE_TOPIC}}/summary/…, {{BASE_TOPIC}}/slot/<n>/…, {{BASE_TOPIC}}/provider/<id>/active|shipment_count|error|last_success. MQTT Gateway V2: add subscription {{BASE_TOPIC}}/#. Empty values (e.g. error without error) are not retained by the broker (MQTT standard), but are delivered live.
  • Loxone: virtual inputs named like in the gateway (/ → _), e.g. {{BASE_TOPIC}}_slot_1_status_code; texts as virtual text inputs.
  • REST: {{API_URL}}?q=summary&format=text&token=… – token under Settings → REST.

Security, logs, backup

  • Credentials are stored on the LoxBerry only (0600), never shown again and never logged. Empty password field = keep value.
  • Errors per carrier on the Carriers page; log lines on Status (log level under Settings → General). Logs are cleared on reboot.
  • Update: install the new ZIP – settings, credentials and shipments are kept.
