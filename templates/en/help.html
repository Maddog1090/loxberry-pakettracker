Pakettracker collects shipments from DHL, Amazon, Hermes, DPD, GLS and UPS and provides them to Loxone via MQTT and HTTP. Detailed guide: the plugin README.

Data sources: DHL and UPS via their official APIs (credentials required) plus e-mails; Amazon, Hermes, DPD and GLS only via their notification e-mails (e-mail input required).

  1. Test mode (Settings → General): while active, no carrier is queried – ideal to set up MQTT and Loxone.
  2. E-mail input (Settings): enter IMAP server, port, encryption, user, (app) password, folders → "Save & test IMAP connection". Mails are only read, never deleted.
  3. DHL: developer.dhl.com → My Apps → app with "Shipment Tracking – Unified" → copy the Consumer Key → Settings → Carriers → DHL.
  4. UPS: developer.ups.com → Apps → app with product "Tracking" → Client ID and Secret → Settings → Carriers → UPS → "Save & test connection".
  5. Amazon, Hermes, DPD, GLS: enable e-mail notifications at the carrier; shipments appear automatically.
  6. Switch off test mode → Status → "Update now". The Carriers page shows health, last success and errors per carrier.
  • Add shipments manually: "Detect automatically" or choose a carrier – a manual choice always wins. Ambiguous numbers (12 or 14 digits) show a hint.
  • MQTT: topics under pakettracker/… (summary, slot/1…N, provider/<id>/active|error|last_success|shipment_count). MQTT Gateway V1 subscribes automatically; for V2 add pakettracker/# manually.
  • HTTP: /plugins/pakettracker/api.php?q=summary&format=text&token=…
  • Security: credentials are stored on the LoxBerry only (0600), never displayed and never logged. Empty password field = keep current value.
  • Update/backup: just install the new ZIP – settings, credentials and shipments are kept.
